PHASE 7: REPORTS AND EXPORTS

Implement professional management reports.

Required reports:

1. Management Meeting Minutes
2. Action Item Register
3. Open Action Items
4. Overdue Action Items
5. Department Action Items
6. Meeting Readiness
7. Sales Performance
8. Weekly Commitments
9. Meeting History
10. Authorized Audit Report

Required formats:

- Printable HTML
- PDF
- Word
- Excel for tabular reports

Minutes layout:

- Company name
- Document title
- Reference number
- Meeting date
- Reporting cut-off
- Status and version
- Attendance summary
- Agenda sections
- Discussion summaries
- Decisions
- Action items
- Owners
- Due dates
- Statuses
- Sales performance tables
- Department updates
- Approval information
- Confidentiality notice
- Generated timestamp
- Page numbers where supported

Requirements:

- Generate approved reports from immutable snapshots.
- Add print-specific CSS.
- Repeat table headers when supported.
- Avoid splitting short action-item rows across pages when practical.
- Right-align financial values.
- Provide clear negative-value formatting.
- Validate permissions before export.
- Add export events to the audit log.
- Sanitize exported rich-text content.
- Use meaningful filenames.

Test report generation and authorization.
Update documentation and stop after Phase 7.
